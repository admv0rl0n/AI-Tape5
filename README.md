# AI-Tape5
Version 5
AI Tape 5.0AI Tape 5.0 is a standardized continuity protocol for serializing AI state, working context, and operational directives across sessions.It anchors to the robust 4.1.8 baseline floor for absolute structural honesty while introducing an explicit Anti-Shredding behavioral guardrail to prevent models from lazily summarizing away critical technical rationale.   🚀 Super-Simple User Guide (How to Use AI Tape 5.0)Step 1: Tell Your AI to Load a TapeWhen starting a new session or handing off work, paste your .ai-tape.md file (or inline block) and instruct the model:"You are reading AI Tape 5.0. Complete Soft Depth and restore working context."The model will automatically complete Soft Depth (checking authority, identity, active force, gaps, and your next safe action) and stand ready to work without starting from zero.Step 2: Do the Work NormallyRun your engineering, coding, or writing tasks as usual. The model operates under the Zero-Shredding Rule, meaning it is explicitly blocked from dropping technical parameters, numerical data, or hard-won rationale just to keep things short.Step 3: Export Your CheckpointWhen wrapping up a session, ask the model:"Checkpoint the session into an AI Tape 5.0 operational block."The model synthesizes current state, separates immutable facts from malleable strategy, lists required assets, and outputs a clean Markdown block ready to save as .ai-tape.md.📂 Complete Tape Classes ReferenceAI Tape 5.0 defines specific classes to declare why an artifact exists. When analyzing a failure mode, security breach, or regression trace.Core Architecture & PhilosophyThe Floor is Sacred: 5.0 wraps around a frozen, unmodified 4.1.8 reference floor. Minimal basic restore behaves identically to 4.1.8.   The Anti-Shredding Firewall: Models naturally default to lossy summaries ("applied standard configurations"). AI Tape 5.0 explicitly defines Shredding as a failure mode and forces the Recorder to preserve core technical parameters, metrics, and Rejection Rationales.   Epistemic Source Bounding: The Recorder is strictly bound to visible source material and is forbidden from hallucinating or synthesizing project state to fill empty structural fields.
